## Histórias de Usuário - Administrador
- Como administrador quero poder enviar os meus vídeos para que eles sejam exibidos para os clientes.
```Critério de aceitação: ```Sabendo que existe uma coletânea de vídeos na página, quando um vídeo for enviado, seja o arquivo em si (mp4, mov, vkm, etc.) ou um link, o vídeo deve ser exibido na página para os clientes.

- Como administrador quero poder incluir minhas fotos no portfólios para criar uma sensação de pessoalidade com os clientes.
```Critério de aceitação: ```Sabendo que existam fotos minhas na página, quando uma foto for enviada, ela deve ser exibida para os clientes.

- Como administrador eu quero poder atualizar o portfólio como entender para transmitir ao máximo a minha personalidade aos clientes.
```Critério de aceitação: ```Sabendo que existem seções de texto na página, quando eu escrever um texto na página, ele deverá ser visualizado pelos clientes.

- Como administrador eu quero poder receber mensagens de clientes para que eu possa conversar com eles e entender o que precisam para que possamos fechar negócio.
```Critério de aceitação: ```Sabendo que há uma área no site para que os clientes possam fazer contato comigo, quando uma mensagem for enviada a mim, eu quero receber uma notificação e poder visualizar a mensagem e quaisquer tipo de informações pessoais disponíveis de maneira instantânea.

- Como administrador quero poder incluir depoimentos de clientes e parceiros para que eu possa adicionar legitimidade a mim.
```Critério de aceitação: ```Sabendo que há uma área de depoimentos na página, quando eu postar um novo depoimento quero que ele seja exibido na página de forma a tentar converter um cliente.

```Critério de aceitação: ```Sabendo que existem várias informações sobre o editor em questão, quando eu entar no site quero que as informações estejam organizadas de forma segregada e organizada de forma a auxiliar a minha tomada de decisão.
