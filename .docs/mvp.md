## Definições do MVP
Neste arquivo estão as especificações sobre o que deve constar no MVP.

### Classificação MOSCOW
- [M] Como administrador quero poder enviar os meus vídeos para que eles sejam exibidos para os clientes.

- [C] Como administrador quero poder incluir minhas fotos no portfólios para criar uma sensação de pessoalidade com os clientes.

- [C] Como administrador eu quero poder atualizar o portfólio como entender para transmitir ao máximo a minha personalidade aos clientes.

- [S] Como administrador eu quero poder receber mensagens de clientes para que eu possa conversar com eles e entender o que precisam para que possamos fechar negócio.

- [W] Como administrador quero poder incluir depoimentos de clientes e parceiros para que eu possa adicionar legitimidade a mim.

- [M] Como cliente quero poder vizualizar o portfólio para que eu possa decidir se este é o editor ideal para o meu negócio.

- [S] Como cliente quero poder fazer contato direto com o edtior para que possamos fechar um contrato.

### Limitação do MVP
- Limitar o fluxo central   
```Eu acesso o meu portfólio, altero como eu bem entender e adiciono os meus vídeos para que eles possam ser visualizados pelos clientes.```
- Definir até cinco ```must```
